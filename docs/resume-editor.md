# 自我介绍内容管理

入口：后台 → 系统设置 → 关于我 → 成就贴纸。

1. 选择人脸上的一个位置（固定 8 个）。
2. 上传 PNG、JPEG 或 WebP 图片，或点击“恢复原贴纸”。推荐透明 PNG，最大 5 MB，宽高不超过 4096 像素。新图在原位置等比居中显示。
3. 编辑标题、英文分类、介绍和标签；右侧卡片实时预览。介绍支持换行，采用纯文本显示。
4. 点击“保存全部成就”。前台刷新后读取新配置，人脸贴纸与介绍卡片使用同一张图片。上传图片本身不会发布修改。

“更多关于我”页签继续编辑原有 Markdown 介绍，单独保存。

## 部署

- 同时更新 server、front、admin。
- 新增 `resume_profile` 表；现有配置默认关闭自动迁移。部署前执行 `server/assets/migrations/20260917_resume_profile.sql`，或启用 `Server.DbAutoMigrate` 后启动服务完成迁移，再恢复原设置。
- 无已保存记录时，接口返回 `server/internal/model/resume-defaults.json` 中的 8 项现有内容。模型和图片不必重新导出。
- 前台配置请求失败时展示内置内容，并提供重试；后台请求失败时禁止编辑未加载的数据。
- 后台开发环境的默认贴纸预览指向 `http://localhost:3333`；自定义前台域名或子路径时，设置 admin 的 `VITE_BLOG_URL` 为前台根地址（不要带末尾斜线）。生产环境默认与后台同域。
- 上传服务继续使用原有 `Upload` 存储配置。图片存储需要允许前后台域名跨域读取；后台上传后会验证图片可读取，避免只在卡片上可见、3D 贴图无法加载。

## 接口与约束

- `GET /api/setting/about?view=resume`：后台读取。
- `PUT /api/setting/about?view=resume`：后台保存，继承原“关于我”的鉴权和权限。
- `GET /api/front/about?view=resume`：前台公开读取。
- 无 `view=resume` 时保持原 Markdown 接口行为。
- 内容保存在独立表，不通过公开网站配置接口写入。
- 一次保存完整的 8 个唯一编号，单行更新；校验失败不覆盖旧数据。
- 标题、分类各最多 60 字，介绍最多 1200 字，标签最多 5 个、每个 24 字。
- 本版本固定贴纸位置与镜头，不提供新增、删除、排序或 3D 位置编辑。
